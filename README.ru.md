# Diter

**Один инструмент — три системы. Кроссплатформенный создатель загрузочных USB-накопителей, который никогда не трогает ваш системный диск.**

Diter — кроссплатформенный инструмент для создания загрузочных USB-носителей.
В отличие от инструментов, которые умеют «записывать только свою половину»,
Diter выбирает правильную стратегию для каждого образа: и Windows ISO, и
установщик macOS, и любой дистрибутив Linux превращаются в **действительно
загрузочный** накопитель — при этом системный диск исключён из выбора.

## Зачем нужен Diter

| Инструмент | Ограничение |
|---|---|
| **Rufus** | Отлично работает в Windows, но не умеет записывать macOS (нет поддержки записи HFS/APFS) |
| **createinstallmedia** | Только Apple, только установщики |
| **Etcher** | `dd` везде, но Windows ISO — не гибридный образ, поэтому `dd` даёт **незагрузочный** накопитель |

Diter направляет каждый образ в подходящий движок вместо слепого `dd`:

| Цель | Стратегия |
|---|---|
| **Windows ISO** | разметка → FAT32 → копирование файлов → загрузочный код (авторазбиение `install.wim > 4 ГБ` через wimlib) |
| **macOS** | трёхуровневая: `createinstallmedia` → `asr` → `raw`, от 10.10 до самых новых версий |
| **Linux** | побайтовая запись всего диска, опциональный постоянный раздел `casper-rw` |

## Возможности

- **Кроссплатформенность** — работает на macOS, Windows и Linux
- **Определение образа** — читает заголовки файла напрямую (ISO9660, GPT, MBR, HFS+, APFS, UDF, DMG) и показывает цепочку признаков
- **Защита системного диска** — три независимых уровня; системный диск нельзя даже выбрать
- **Привилегированный помощник** — авторизация запускает фоновый процесс без окна, поэтому главное окно не перезапускается и выбранные параметры сохраняются
- **Проверка после записи** — обратное чтение всего накопителя и сравнение SHA-256
- **Внешний вид** — светлая / тёмная / системная тема
- **Локализация** — 6 языков: 简体中文, 繁體中文, English, 한국어, العربية, Русский

## Модель безопасности

1. **Перечисление** — каждое устройство получает `verdict`; заблокированные исключаются из выбора
2. **Подтверждение** — чекбокс + удержание 1,5 секунды
3. **Перед записью** — повторное перечисление, сравнение ёмкости, повторный `assertWritable()`

На macOS проверка системного диска нетривиальна: корневой том `/` находится на
*синтезированном* контейнере APFS, поэтому код прослеживает `APFSPhysicalStores`
до физического диска, чтобы избежать ложных срабатываний. Проверено на реальном
оборудовании.

## Начало работы (разработка)

```bash
npm install          # при первом запуске скачивает рантайм Electron
npm run preview      # только сборка превью интерфейса (Electron не нужен)
npm start            # сборка и запуск десктопного приложения
```

Превью интерфейса (`preview/diter-preview.html`) — это один автономный файл на
моковых данных; он никогда не трогает реальный диск.

## Готовые сборки (`release/`)

| Сборка | Платформа | Примечание |
|---|---|---|
| `Diter-1.0.2-mac-x64.dmg` | macOS (x64) | Без подписи — при первом запуске нужен правый клик → Открыть |
| `Diter-1.0.2-win-x64.zip` | Windows (x64) | Портативная версия, без установщика (храните папку целиком) |

Пересборка: `npm run package` (см. `build/package.sh`).

> **Примечание для Windows**: если при запуске `Diter.exe` появляется ошибка
> «VCRUNTIME140_1.dll / MSVCP140.dll не найден, попробуйте переустановить»,
> значит, в системе нет распространяемого пакета Microsoft Visual C++
> 2015–2022 (он нужен приложениям на Electron). Запустите прилагаемый
> `vc_redist.x64.exe` и снова откройте Diter.

## Технологии

(никаких нативных зависимостей Rust/Go для компиляции).

## Статус и планы

Готово: определение образов, оценка безопасности дисков, движки записи, полный
интерфейс и сценарии, привилегированный помощник, проверка.

Планируется: встроить `wimlib`/`ms-sys` в пакет; перенести помощник macOS на
`SMJobBless`; блокировка томов Windows (`FSCTL_LOCK_VOLUME`).
