Diter 隐私政策

发布者：nocrashtodaytech　·　生效日期：2026 年 11 月 15 日　·　适用于 Diter 桌面应用（Windows / macOS / Linux）

Diter 是一款在本机运行的 USB 启动盘制作工具。我们不收集、不上传、不出售任何个人数据。应用没有账号体系、没有广告、没有第三方统计或崩溃上报 SDK。绝大多数功能完全离线工作。

1. 应用在你电脑上保存的数据

以下数据仅保存在本机的应用数据目录，不会上传到任何服务器：

  • 偏好设置：界面语言、外观模式（浅色 / 深色 / 跟随系统）、捐助提示是否已展示。
  • 任务历史与日志：写入、擦除、备份任务的时间、类型、结果、错误信息及日志文件。日志可能包含你所选镜像的文件名/路径与目标磁盘名称。
  • 临时更新包：仅在你确认更新后，从 GitHub 下载的安装包会暂存于系统临时目录，安装完成即删除。

这些数据只用于应用自身功能与排查问题。你可以随时删除本机应用数据目录来清除它们。

2. 网络访问

  • 检查更新（自动）：应用启动后向 api.github.com 的 GitHub Releases 接口查询最新版本号。请求仅携带 User-Agent: Diter-Updater 与当前版本信息，不含任何个人信息、设备标识或文件/磁盘内容。
  • 下载更新（手动）：仅当你主动点击下载更新，应用才会从 GitHub 获取安装包。
  • 外部链接（手动）：点击「捐助」「关于」中的链接时，会用系统默认浏览器打开爱发电（afdian.com）或哔哩哔哩（space.bilibili.com）。这些站点有各自的隐私政策，其内容与数据处理由相应站点负责，Diter 不接收、不共享任何信息给它们。

3. 本地文件与磁盘访问（核心功能）

以下操作全部在本机完成，且均由你主动发起：

  • 枚举本机磁盘与 USB 设备（型号、容量、总线类型等），用于选择目标设备；
  • 读取你主动选择的镜像文件；
  • 写入、擦除或备份你主动选定的目标磁盘。执行前应用会要求管理员 / root 授权并再次确认。
请注意：写入启动盘会清空目标磁盘上的全部数据，操作前请自行备份。磁盘内容不会被上传或发送到任何服务器。

4. 我们不会收集的信息

姓名、邮箱、电话、通讯录、精确位置、设备唯一标识符、浏览历史、使用统计、崩溃报告、生物识别信息，以及你镜像文件与磁盘中的数据内容。

5. 权限与提权

写入物理磁盘需要管理员 / root 权限。应用会临时启动一个无界面的本地提权助手进程，通过本机 socket 与主窗口通信；该进程不联网、不访问网络，任务结束后退出。

6. 第三方服务与数据共享

应用内未嵌入任何第三方 SDK。涉及的外部服务仅限上述 GitHub（版本查询与更新下载）、爱发电及哔哩哔哩（用户主动跳转）。我们不向任何第三方共享、出售或出租数据——事实上我们并不持有你的数据。除法律法规明确要求外，也无数据可对外披露。

7. 数据安全与保留

所有数据留在本机，受你的操作系统账户权限保护。请妥善保管日志文件（可能包含本地文件路径）。我们不设置远程数据保留期，因为你可随时在本机删除。

8. 儿童隐私

Diter 不面向 13 岁以下儿童，也不会有意收集儿童的任何信息。

9. 政策变更

如本政策有更新，将在本页面公布并修改顶部「生效日期」。重大变更会在应用内提示。

10. 联系我们

如有隐私相关问题，请通过项目仓库提交 Issue：github.com/nocrashtodaytech/Diter。

Privacy Policy — Diter

Publisher: nocrashtodaytech　·　Effective date: November 15, 2026　·　Applies to the Diter desktop app (Windows / macOS / Linux)

Diter is a USB bootable-drive creator that runs locally on your computer. We do not collect, upload, or sell any personal data. The app has no account system, no advertising, and no third-party analytics or crash-reporting SDK. Nearly all functionality works entirely offline.

1. Data stored on your computer

The following data is stored only in the local app data directory and is never uploaded:

  • Preferences: interface language, appearance mode (light / dark / system), and whether the donation prompt has been shown.
  • Task history and logs: time, type, outcome, error messages, and log files for write / erase / backup tasks. Logs may contain the file name or path of the image you selected and the name of the target disk.
  • Temporary update package: an installer downloaded from GitHub only after you confirm an update, stored in the system temp directory and deleted once installation finishes.

This data is used solely for the app's own functionality and troubleshooting. You can delete the local app data directory at any time to remove it.

2. Network access

  • Update check (automatic): on startup the app queries the GitHub Releases API at api.github.com for the latest version. The request carries only User-Agent: Diter-Updater and version information — no personal data, device identifiers, or file/disk contents.
  • Update download (manual): an installer is fetched from GitHub only when you explicitly choose to update.
  • External links (manual): clicking the donation or about links opens afdian.com or space.bilibili.com in your system browser. Those sites have their own privacy policies and are responsible for their own data handling; Diter does not send or share any information with them.

3. Local file and disk access (core functionality)

All of the following happens locally and is initiated by you:

  • Enumerating local disks and USB devices (model, capacity, bus type) so you can pick a target;
  • Reading the image file you explicitly select;
  • Writing to, erasing, or backing up the disk you explicitly select. The app requests administrator / root authorization and a confirmation beforehand.
Note: writing a bootable drive erases all data on the target disk — please back it up first. Disk contents are never uploaded or transmitted to any server.

4. What we do not collect

Names, email addresses, phone numbers, contacts, precise location, unique device identifiers, browsing history, usage statistics, crash reports, biometric data, or the contents of your images and disks.

5. Privileges and elevation

Writing to a physical disk requires administrator / root privileges. The app temporarily launches a headless local helper process that communicates with the main window over a local socket. This process has no network access and exits when the task finishes.

6. Third parties and data sharing

No third-party SDKs are embedded. The only external services involved are GitHub (version check and update download) and afdian.com / bilibili.com (user-initiated links). We do not share, sell, or rent data to anyone — we do not hold your data in the first place, and have nothing to disclose except where required by law.

7. Data security and retention

All data stays on your device, protected by your operating system account permissions. Please keep log files private as they may contain local file paths. We set no remote retention period because you can delete the data locally at any time.

8. Children's privacy

Diter is not directed at children under 13, and we do not knowingly collect any information from children.

9. Changes to this policy

Updates will be posted on this page with a revised effective date. Material changes will also be noted in the app.

10. Contact us

For privacy questions, please open an issue at github.com/nocrashtodaytech/Diter.
